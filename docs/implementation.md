# Implementation status

This first increment uses the supplied Workday Planner PRD as product input and the user's name and visual requirements as the app identity. The source document has not been modified.

## Architecture

- `RingCore/Models.swift`: task intent and scheduling states, raw captures, routine templates, settings and dated plans.
- `RingCore/Scheduler.swift`: pure planning from a controlled clock and supplied calendar snapshot, independent of AI and network access.
- `RingCore/Repository.swift`: canonical JSON files in a dedicated Git repository, a journal for interrupted writes, and explicit save failures.
- `RingPlanner/PlannerStore.swift`: main-actor coordinator that persists mutations before acknowledging them.
- `RingPlanner/App.swift`: application lifecycle, native menu bar popover, persistent main window and global keyboard capture.
- `RingCore/TaskTriage.swift`: shared validation gate for menu selections and drops. Proposed classification is kept in memory until required planning fields are confirmed.
- `RingCore/TaskLifecycle.swift`: pure archive, Inbox and deletion changes across tasks, dated plans and capture references, persisted together by the repository's write/deletion journal.
- `PlanTaskSelectionSheet.swift`, `ArchivedTasksView.swift`: per-day task checklists and archived-task inspection/restoration.
- `RingCore/RoutineSchedule.swift`, `RingPlanner/RoutineViews.swift`: weekday recurrence, validation, routine creation and editing, and readable schedule summaries.
- `RingCore/PlanningPreview.swift`: available-time accounting and selected-task fit from the same scheduler as saved plans, without persistence.
- `CalendarPublication.swift`, `GoogleCalendarPublishing.swift`, `CalendarPublishingStore.swift`: durable confirmation snapshots, scoped calendar writes and retry/reconciliation.
- `TaskSlotPlanner.swift`, `TaskSlotStore.swift`, `TaskSlotSheet.swift`: Q2 slot proposals, alternatives, conflict revalidation and individually accepted bookings.
- `InboxSidebar.swift`, `PriorityMatrix.swift`, `TaskDragTitle.swift`, `PriorityReviewSheet.swift`: persistent right-side Inbox, inline priority menus, app-local pointer dragging, and cancellable missing-detail review.
- SwiftUI surfaces: Today, Inbox sidebar, matrix, routines, evening review, preferences, capture and task editing.
- `SpeechCapture.swift`: explicit on-device Apple recognition, a 60-second cap, cancellable permission checks and typed fallback. `QuickCaptureView.swift` renders the separate capture panel. Inbox owns its draft in the store and receives partial transcripts through a session-scoped callback.

## Deliberate constraints

Drafts include meeting availability after direct Google authorization and explicit selection. Calendar connection state and last local read remain visible. Normal task data is never seeded with sample work. Protected occurrences are preserved on replanning while their routine remains enabled for that day. Explicitly turning off a routine or repeat day removes unstarted occurrences on replan, including pins. Completed and running occurrences remain independent of template changes. Calendar time passing does not finish tasks. A task's age does not change its priority.
