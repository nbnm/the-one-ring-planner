# Personal Library implementation

Visual thesis: a quiet parchment and charcoal reference collection, with content previews, Palatino headings and a single gold action.

Content plan: one full-width Library workspace; title/search/capture in the toolbar, one collection menu, gallery/list, and a temporary reader. Metadata and service details stay collapsed or in Settings.

Interaction thesis: brief reader opacity transitions, a restrained gallery/list change, and clear focus return to the selected note. Reduce Motion removes transitions. Existing recording and save warnings remain visible.

Stages: (1) local notes and shared capture; (2) bounded Git backup, independent archive, isolated restore; (3) opt-in AI organization, OCR and capability-checked semantic retrieval; (4) durable Telegram service and native import.

Use temporary demo repositories and mocked services throughout. No real planner data, credentials, calendars, recordings or remote data repositories are used for development checks.
